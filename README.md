# SOL - GrannyHelp

Projet 2 SOL : Solidarite intergenerationnelle

GrannyHelp est une application de mise en relation entre des jeunes et des personnes agees pour des services du quotidien : courses, menage, petit bricolage, aide informatique, etc.

Le projet reprend la direction UX proposee par Sofiane :

- Nom : GrannyHelp
- Signature : Petits services. Grands liens.
- Promesse : un coup de main simple, local et humain
- Utilisateurs principaux : jeune volontaire, accompagnateur, personne agee autonome ou accompagnee

## Objectif produit

Permettre a une personne agee, ou a son accompagnateur, de trouver une aide proche, disponible et adaptee au besoin. Le service peut etre ponctuel ou regulier. Le pourboire reste libre et se fait directement entre les personnes.

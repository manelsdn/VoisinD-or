# SOL - GrannyHelp

Projet 2 SOL : Solidarité intergénérationnelle

GrannyHelp est une application de mise en relation entre des jeunes et des personnes âgées pour des services du quotidien : courses, ménage, petit bricolage, aide informatique, etc.

Le projet reprend la direction UX proposée par Sofiane :

- Nom : GrannyHelp
- Signature : Petits services. Grands liens.
- Promesse : un coup de main simple, local et humain
- Utilisateurs principaux : jeune volontaire, accompagnateur, personne âgée autonome ou accompagnée

## Site de présentation

Le dépôt contient maintenant un site statique à la racine :

- `index.html` : site de présentation du projet
- `styles.css` : mise en forme
- `app.js` : navigation entre les pages

Le site contient trois grandes parties :

- **UX** : reprise structurée du travail de Sofiane, avec proposition de service, charte graphique, personas, parcours UX, storyboard et validation.
- **PO** : partie de Manel, avec Lean Canvas, modalités de fonctionnement, Roadmap V0, EPICs, user stories et priorités J2.
- **Maquette** : résumé des écrans principaux et lien avec les fonctionnalités à développer.

## Objectif produit

Permettre à une personne âgée, ou à son accompagnateur, de trouver une aide proche, disponible et adaptée au besoin. Le service peut être ponctuel ou régulier. Le pourboire reste libre et se fait directement entre les personnes.

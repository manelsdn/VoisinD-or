# Lean Canvas - GrannyHelp

Projet 2 SOL : Solidarite intergenerationnelle

Ce Lean Canvas resume la vision produit de GrannyHelp pour la J2. Il sert a expliquer le probleme, les utilisateurs, la solution et la valeur du projet.

## Lean Canvas

| Bloc | Contenu pour GrannyHelp |
| --- | --- |
| Probleme | Les personnes agees peuvent avoir besoin d'aide pour des taches simples du quotidien. Les proches ne sont pas toujours disponibles. Les jeunes qui veulent aider ne savent pas toujours ou trouver des besoins proches et clairs. |
| Segments utilisateurs | Personnes agees autonomes, accompagnateurs familiaux ou associatifs, jeunes volontaires disponibles dans le quartier. |
| Proposition de valeur unique | Petits services. Grands liens. Une application simple pour trouver une aide locale, humaine et adaptee au quotidien des personnes agees. |
| Solution | Mise en relation par proximite, disponibilite et type de service. Possibilite de demander pour soi ou pour un proche. Demandes ponctuelles ou regulieres. Messagerie pour se mettre d'accord. |
| Canaux | Application web mobile, site vitrine, bouche-a-oreille local, associations, familles, structures d'accompagnement. |
| Sources de revenus | Pour la maquette : pas de revenu gere. Le pourboire est libre et se fait directement entre le jeune et la personne agee. Plus tard : partenariats locaux ou associations. |
| Structure de couts | Hebergement Firebase, maintenance de l'application, moderation, communication locale, support utilisateurs. |
| Indicateurs cles | Nombre de demandes creees, nombre de jeunes inscrits, demandes acceptees, temps moyen pour trouver une aide, satisfaction apres service. |
| Avantage injuste | Un parcours pense aussi pour les accompagnateurs et les personnes agees sans smartphone. Le projet ne vend pas seulement un service : il cree du lien social local. |

## Hypotheses principales

| Hypothese | Pourquoi c'est important | Comment la verifier |
| --- | --- | --- |
| Les accompagnateurs sont un utilisateur cle | Beaucoup de personnes agees n'utilisent pas facilement une application | Tester le parcours "Pour Madeleine" avec des proches aidants |
| La proximite rassure les utilisateurs | Un service de quartier semble plus simple et plus humain | Observer si les utilisateurs filtrent d'abord par distance |
| La disponibilite doit etre claire | Un besoin simple devient complique si le creneau n'est pas clair | Tester la creation d'une demande avec date et heure |
| Le pourboire doit rester secondaire | Le sujet insiste sur un pourboire libre et direct | Verifier que les utilisateurs comprennent qu'il n'y a pas de paiement dans l'app |

## Formulation courte pour l'oral

GrannyHelp repond a un probleme simple : les personnes agees ont parfois besoin d'un petit coup de main, mais les proches ne sont pas toujours disponibles et les jeunes volontaires ne savent pas ou proposer leur aide. Notre solution met en relation les personnes selon trois criteres : proximite, disponibilite et type de service. L'application gere aussi le cas important de l'accompagnateur qui organise une aide pour un proche.

# Designer - livrables UX GrannyHelp

Ce dossier regroupe les livrables Designer / UX du projet SOL - GrannyHelp.

## Fichiers

- `dossier-designer-grannyhelp.html` : page de synthèse UX à présenter.
- `assets/logo-grannyhelp.png` : logo du projet avec un nom de fichier clair.
- `assets/video-presentation-grannyhelp.mp4` : vidéo de présentation.
- `assets/illustration-rencontre-perron.png` : illustration principale.
- `assets/illustration-mamie.png` : illustration secondaire.
- `assets/persona-camille-accompagnatrice.png` : persona accompagnatrice.
- `assets/persona-lucas-jeune-volontaire.png` : persona jeune volontaire.
- `assets/persona-madeleine-beneficiaire.png` : persona bénéficiaire.

## Ce que couvre le dossier

- Nom de marque, logo et slogan.
- Deux pistes de positionnement.
- Charte graphique : couleurs, typographies, iconographie et ton.
- Maquettes principales : inscription, connexion et accueil.
- Personas, storyboard et user journey map.
- Value Proposition Canvas avec deux profils de marketplace.
- Site vitrine : offre, services, tarifs, partenaires, FAQ, témoignages, cadre légal et contact.
